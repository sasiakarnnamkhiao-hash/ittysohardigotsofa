    • • ระบุราคา ( ป้ายขาย )
    • • ระบุเรทเช่า ( ป้ายเช่า )
    • • ระบุจำนวนสกิน ( SS / S / A )
    • • ระบุบ้าน ( หรือไม่ใส่แจ้งได้ค่ะ )
